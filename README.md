## 🎮 About the Game

Ultrapool is a single-player roguelike pool deckbuilder developed by Icedrop Games and released on August 24, 2026. It combines arcade pool physics with strategic ball building, shop management, and run-based progression.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Ultrapool**. This trainer provides optional quality-of-life and progression controls for Ultrapool runs. Adjust shots, score, money, ball collections, shop options, and round difficulty while preserving the game's pool-based roguelike structure.

**Target Audience:** Players who want to practice trickshots, test unusual ball synergies, explore cocktail-bar fusions, experiment with snacks and cubes, or reduce the difficulty of long roguelike runs.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Infinite Shots** — Prevents the current round from ending when the normal shot supply is exhausted.
- **Score Multiplier** — Increases score gained from pocketed balls and helps reach round score targets faster.
- **Add Money** — Adds bar currency for purchasing and improving balls, snacks, and other run upgrades.
- **Unlock Ball Collection** — Unlocks available ball sets and special balls for broader build experimentation.
- **Free Shop Purchases** — Allows shop items to be purchased without spending the run's money.
- **Ball Fusion Control** — Supports experimentation with cocktail-bar fusion combinations by reducing or removing the usual purchase cost.
- **Round Protection** — Helps preserve the current run when a difficult round would otherwise end the attempt.
- **Instant Trickshot Resolution** — Speeds up shot resolution and reduces downtime between table actions.
- **Difficulty Override** — Adjusts the active run difficulty for testing builds and practicing higher-level challenges.

### ⚔️ Combat

- **No Combat System** — Ultrapool has no conventional combat. The trainer's action controls apply to shots, ball effects, score targets, and round progression instead.

## 📖 Detailed Feature Guide

### Movement & Exploration

Ultrapool does not use character movement. Gameplay centers on positioning the aiming direction, selecting shot strength, and controlling the cue ball to pocket balls and trigger their effects. Use Infinite Shots and Instant Trickshot Resolution when practicing angles or testing unusual table setups.

### Tools & Inventory

Your run is built around a collection of special balls, snacks, and cubes. Use Add Money and Free Shop Purchases to test different builds, then use Ball Fusion Control to experiment with cocktail-bar combinations. Unlock Ball Collection is best used for exploring the game's themed ball sets.

### World & Environment

Each run takes place across escalating pool rounds. Pocketed balls provide score, successful scoring generates money, and the bar shop offers new balls and improvements between rounds. Round Protection and Difficulty Override are useful for studying later stages without restarting an entire run.

### Combat & Weapons

There is no combat in Ultrapool. The main challenge is meeting increasing score requirements before running out of shots. Score Multiplier, Infinite Shots, and Round Protection support practice by extending a round and making it easier to evaluate ball abilities and trickshot strategies.
